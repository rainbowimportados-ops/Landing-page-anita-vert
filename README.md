# Instituto Vert — cartão digital

Página mobile-first de contatos e agendamentos do Instituto Vert.

## Conteúdo

- WhatsApp para as unidades de Franca e Ribeirão Preto
- resultados clínicos reais autorizados
- vídeo vertical otimizado
- Instagram e rotas no Google Maps
- download do contato em formato vCard
- área para dentistas

## Desenvolvimento

```bash
npm install
npm run dev
```

O build de produção é gerado com `npm run build` na pasta `dist`.
